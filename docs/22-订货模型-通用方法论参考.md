# 日本化妆品日用品订货模型规则

> 适用业务：日本化妆品日用品零售电商  
> 订货模式：按月订货，季度滚动更新  
> 版本：V1.0

---

## 一、模型概述

### 1.1 核心目标
在缺货风险与资金占用之间找到平衡点，通过科学的订货模型降低库存成本，同时保障销售不断货。

### 1.2 业务约束条件

| 约束项 | 说明 | 模型适配 |
|--------|------|----------|
| 订货频率 | 按月向日本供货商下单 | 以月为单位做滚动计划 |
| 到货周期 | 国际物流+清关时间 | 在计算中预留充足周期 |
| 起订量(MOQ) | 供应商有最低订货量要求 | 最终订货量需满足MOQ约束 |
| 计划跨度 | 半年（6个月）需求计划 | 每季度滚动更新一次 |
| 波动处理 | 不同品类销售波动差异大 | 分品类设定波动系数 |

### 1.3 核心公式总览

```
基础备货数 = 预测月均销量 × (到货周期月数 + 安全覆盖月数)

波动调整后需求 = 基础备货数 × 品类波动系数 × 季节性调整因子 × 趋势调整因子

最终订货量 = 满足MOQ约束的波动调整后需求
```

## 二、半年需求计划框架

### 2.1 时间轴规划

```
当前时间点
    │
    ▼
┌─────────────────────────────────────────────────────────┐
│  第1月    第2月    第3月    第4月    第5月    第6月      │
│  ─────    ─────    ─────    ─────    ─────    ─────    │
│  确定单    预订单    预订单    预订单    预订单    预订单  │
│  (已发)   (基础)   (基础)   (基础)   (基础)   (基础)   │
│            +波动    +波动    +波动    +波动    +波动    │
└─────────────────────────────────────────────────────────┘
         ↑
    每季度重新计算并滚动推进
```

### 2.2 计划类型说明

| 月份 | 计划类型 | 说明 |
|------|----------|------|
| 第1月 | 确定订单 | 已发给供应商的正式订单 |
| 第2-3月 | 预测订单 | 供供应商备原料/产能规划 |
| 第4-6月 | 参考预测 | 长期趋势参考，精度较低 |

### 2.3 滚动更新机制

- **更新频率**：每季度初（1月/4月/7月/10月）
- **更新内容**：
  1. 重新计算过去6个月实际销量
  2. 调整各SKU品类分类
  3. 更新波动系数
  4. 生成新的6个月需求计划

## 三、基础备货数计算

### 3.1 公式

```
基础备货数 = 预测月均销量 × (到货周期 + 安全覆盖月数)
```

### 3.2 参数详解

#### 3.2.1 预测月均销量

**计算方法：**
```
预测月均销量 = 过去6个月销量总和 ÷ 6
```

**异常值处理：**
- 剔除大促月份（如618、双11）的异常高值
- 剔除断货月份（销量为0或极低）的异常低值
- 如有明显趋势（上升/下降），采用加权平均（近3月权重60%，前3月权重40%）

#### 3.2.2 到货周期

**标准到货周期参考：**

| 物流方式 | 周期（月） | 说明 |
|----------|-----------|------|
| 空运直发 | 0.5-1 | 成本高，适合紧急补货 |
| 海运拼箱 | 1.5-2 | 常规方式，平衡成本与时效 |
| 海运整柜 | 1-1.5 | 大批量，成本最低 |

**建议**：按实际历史到货时间统计，取平均值+0.25月缓冲

#### 3.2.3 安全覆盖月数

| 品类 | 安全覆盖月数 | 说明 |
|------|-------------|------|
| A类-爆款 | 1个月 | 需求波动大，需充足缓冲 |
| B类-常规 | 0.5个月 | 适度缓冲 |
| C类-长尾 | 0.5个月 | 低库存策略 |

### 3.3 计算示例

**SKU：某防晒乳液（A类爆款）**

| 参数 | 数值 | 说明 |
|------|------|------|
| 过去6个月销量 | 800, 1200, 600, 1000, 900, 1100 | 剔除大促异常值后 |
| 预测月均销量 | 933件 | (800+1200+600+1000+900+1100)÷6 |
| 到货周期 | 1.5月 | 海运拼箱平均时效 |
| 安全覆盖月数 | 1月 | A类爆款标准 |
| **基础备货数** | **2333件** | 933 × (1.5 + 1) |

## 四、波动系数模型

### 4.1 品类分类标准

#### 4.1.1 分类维度

| 品类 | 销量标准 | 销售额占比 | 波动系数范围 |
|------|----------|-----------|-------------|
| **A类-爆款** | 月销 > 500件 | TOP 20% | 1.3 - 1.5 |
| **B类-常规款** | 月销 100-500件 | 中间60% | 1.1 - 1.2 |
| **C类-长尾款** | 月销 < 100件 | 底部20% | 1.0 - 1.1 |

#### 4.1.2 分类调整规则

- **升级规则**：连续3个月销量突破上一档标准，下季度升级
- **降级规则**：连续3个月销量低于当前档标准，下季度降级
- **新品处理**：上架前3月按B类管理，之后根据实际销量重新分类

### 4.2 基础波动系数

| 品类 | 基础波动系数 | 适用场景 |
|------|-------------|----------|
| A类-爆款 | 1.4 | 网红爆款、季节性爆款 |
| A类-爆款 | 1.3 | 稳定畅销款 |
| B类-常规 | 1.2 | 有一定波动 |
| B类-常规 | 1.1 | 非常稳定 |
| C类-长尾 | 1.1 | 低频但有规律 |
| C类-长尾 | 1.0 | 极低频，按需补货 |

### 4.3 季节性调整因子

#### 4.3.1 化妆品季节性特征

| 季节 | 月份 | 热门品类 | 调整因子 |
|------|------|----------|----------|
| 春季 | 3-5月 | 防晒、美白、清爽型 | 1.2 |
| 夏季 | 6-8月 | 防晒、控油、轻薄型 | 1.3 |
| 秋季 | 9-11月 | 保湿、修复、滋润型 | 1.2 |
| 冬季 | 12-2月 | 滋润、护肤、护手霜 | 1.2 |

#### 4.3.2 大促月份

| 大促 | 月份 | 调整因子 | 说明 |
|------|------|----------|------|
| 38女王节 | 3月 | 1.3 | 美妆品类爆发 |
| 618 | 6月 | 1.5 | 全品类大促 |
| 双11 | 11月 | 1.5 | 全年最大促 |
| 双12 | 12月 | 1.3 | 年终大促 |

### 4.4 趋势调整因子

| 趋势判断 | 计算标准 | 调整因子 |
|----------|----------|----------|
| 快速上升 | 近3月环比平均增长 > 20% | 1.2 |
| 上升趋势 | 近3月环比平均增长 10%-20% | 1.1 |
| 稳定 | 近3月环比波动 < 10% | 1.0 |
| 下降趋势 | 近3月环比平均下降 10%-20% | 0.9 |
| 快速下降 | 近3月环比平均下降 > 20% | 0.8 |

**趋势判断公式：**
```
环比增长率 = (本月销量 - 上月销量) ÷ 上月销量 × 100%
```

### 4.5 波动系数计算示例

**SKU：某防晒乳液（夏季爆款）**

| 调整项 | 系数 | 说明 |
|--------|------|------|
| 基础波动系数 | 1.4 | A类爆款标准 |
| 季节性调整 | 1.3 | 夏季防晒旺季 |
| 趋势调整 | 1.1 | 近3月环比上升15% |
| **综合波动系数** | **2.00** | 1.4 × 1.3 × 1.1 |

## 五、起订量(MOQ)处理规则

### 5.1 决策流程

```
波动调整后需求 = 基础备货数 × 综合波动系数

IF 波动调整后需求 < MOQ:
    最终订货量 = MOQ
    标记：需评估是否值得订货
    
ELSE IF MOQ < 波动调整后需求 ≤ 2×MOQ:
    最终订货量 = 2×MOQ（向上取整）
    标记：标准订货
    
ELSE IF 2×MOQ < 波动调整后需求 ≤ 3×MOQ:
    最终订货量 = 3×MOQ（向上取整）
    标记：增量订货
    
ELSE:
    最终订货量 = ROUNDUP(波动调整后需求 / MOQ) × MOQ
    标记：大批量订货
```

### 5.2 低需求SKU处理策略

当波动调整后需求 < MOQ时：

| 策略 | 适用场景 | 操作方式 |
|------|----------|----------|
| 凑单订货 | 同一供应商有多个SKU需补货 | 合并订单满足MOQ |
| 延迟订货 | 库存尚可支撑 | 推迟至下月与其他SKU合并 |
| 提高系数 | 该SKU即将进入旺季 | 适当提高波动系数至MOQ以上 |
| 放弃补货 | 长期滞销 | 清库存后不再补货 |

### 5.3 MOQ计算示例

**SKU：某防晒乳液**

| 参数 | 数值 |
|------|------|
| 基础备货数 | 2333件 |
| 综合波动系数 | 2.00 |
| 波动调整后需求 | 4666件 |
| MOQ | 1000件 |
| 计算 | 4666 ÷ 1000 = 4.67 |
| 向上取整 | 5倍MOQ |
| **最终订货量** | **5000件** |

## 八、常见问题与解决方案

### 8.1 预测不准怎么办？

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 系统性高估 | 波动系数设置过高 | 复盘历史预测vs实际，下调系数 |
| 系统性低估 | 未考虑突发爆款 | 建立爆款识别机制，快速响应 |
| 季节性偏差 | 季节因子设置不当 | 按品类细化季节因子 |
| 趋势判断错误 | 趋势数据不足 | 增加趋势判断的数据周期 |

### 8.2 库存积压怎么办？

| 场景 | 处理方案 |
|------|----------|
| A类爆款积压 | 加大促销力度，快速出清 |
| B类常规积压 | 下调下季度波动系数，控制进货 |
| C类长尾积压 | 考虑清仓，停止补货 |
| 全品类积压 | 全面下调波动系数，优化品类结构 |

### 8.3 供应商交期不稳定怎么办？

| 措施 | 说明 |
|------|------|
| 增加安全覆盖月数 | 将安全覆盖从0.5月增至1月 |
| 开发备选供应商 | 同一SKU寻找2-3家供应商 |
| 建立安全库存 | 对A类爆款维持1-2个月安全库存 |
| 空运应急 | 紧急情况下采用空运补货 |

## 九、附录

### 9.1 计算公式汇总

```
预测月均销量 = SUM(过去6个月销量) ÷ 6

基础备货数 = 预测月均销量 × (到货周期 + 安全覆盖月数)

综合波动系数 = 基础波动系数 × 季节性调整因子 × 趋势调整因子

波动调整后需求 = 基础备货数 × 综合波动系数

最终订货量 = ROUNDUP(波动调整后需求 ÷ MOQ) × MOQ
```

|------|----------|----------|----------|

| 安全覆盖月数 | 1月 | 0.5月 | 0.5月 |
| 补货优先级 | 高 | 中 | 低 |
